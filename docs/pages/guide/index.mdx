# Guide Overview

Learn how to use `tship` to its fullest potential. This guide covers:

- **Configuration** – All available options and how to merge them.
- **Dual-format output** – Building CJS and ESM side by side.
- **Declaration files** – Generating `.d.ts`/`.d.cts`/`.d.mts`.
- **Auto-exports** – Automatically maintaining `package.json` exports.
- **Watch mode** – Efficient rebuilds during development.
- **Monorepo** – Using `tship` with workspaces and project references.
